# Click if you want

Игра-кликер для телефонов и браузера.

---

## 📱 Варианты, как играть с телефона без компьютера:

### 🌟 Вариант 1: Запуск через мобильный браузер / Установка как Web App (Рекомендуется)
Игра работает прямо в браузере любого смартфона (Chrome, Safari, Samsung Internet, Яндекс) с полным сохранением счёта и тактильной отдачей.
1. Откройте страницу игры в браузере телефона.
2. Нажмите в меню браузера (три точки) **«Добавить на главный экран»** (или **«Установить приложение»**).
3. На экране вашего телефона появится полноценная иконка игры — она запускается во весь экран без адресной строки браузера и работает 100% офлайн!

---

### 🎮 Вариант 2: Запуск через официальный Godot на телефоне (из Google Play)
В Google Play есть официальное бесплатное приложение **Godot Engine 4** для Android:
1. Установите **[Godot Engine 4 в Google Play](https://play.google.com/store/apps/details?id=org.godotengine.editor.v4)** на телефон.
2. Скачайте архив проекта: 👉 **[Click_if_you_want_Godot_Project.zip](https://github.com/k98879971-bit/-/raw/arena/019fec8d-repo/Click_if_you_want_Godot_Project.zip)**
3. Откройте Godot на телефоне → нажмите **Импорт (Import)** → выберите скачанный `.zip` архив.
4. Нажмите **Запуск (Play)** — игра запустится на движке Godot прямо на вашем телефоне!
