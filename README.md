# Click if you want

Игра-кликер для мобильных устройств (Android) и браузера.

---

## 📱 Как скачать и установить APK на телефон без ПК

### Способ 1: Прямая ссылка из репозитория
1. Откройте на телефоне ссылку:
   👉 **[Скачать Click_if_you_want.apk](https://github.com/k98879971-bit/-/raw/arena/019fec8d-repo/Click_if_you_want.apk)**
2. После скачивания откройте файл **`Click_if_you_want.apk`** в уведомлениях или папке «Загрузки».
3. Если Android запросит разрешение на установку приложений из браузера/источника — нажмите **«Разрешить»**.
4. Нажмите **«Установить»** и запускайте игру!

## 🎮 Возможности мобильной версии:
- 👆 Плавный отзывчивый кликер с анимациями нажатия и всплывающими очками `+1`

- 📱 Адаптивный дизайн под любые экраны смартфонов
- 📴 Работает на 100% офлайн (без интернета)
