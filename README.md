# Click if you want

Простая игра-кликер, созданная на Godot Engine.

## 📱 Как установить и играть на телефоне (без ПК)

1. Откройте страницу релизов: **[Releases](https://github.com/k98879971-bit/-/releases)**
2. В последнем релизе (v1.0.0) нажмите на **`Click_if_you_want.apk`**, чтобы скачать его на телефон.
3. Откройте загруженный файл `.apk` в шторке уведомлений или в папке «Загрузки» на смартфоне.
4. Если система спросит разрешение на установку из неизвестных источников / браузера — нажмите **Разрешить**.
5. Нажмите **Установить** и запускайте игру!
